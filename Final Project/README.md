# Mercy Mind Therapy – Mental Health Support Platform

Mercy Mind Therapy is a role-based web application developed using PHP, PDO, MySQL, and Tailwind CSS.  
The platform allows patients to request therapy sessions, doctors to view assigned patients, and admins to manage the entire system.

## 🔑 User Roles
- **Admin**
  - Manage doctors (add, edit, delete)
  - Manage patients (view, edit, delete)
  - View session requests
  - Assign doctors and session timings
  - View registered dates and dashboard statistics
